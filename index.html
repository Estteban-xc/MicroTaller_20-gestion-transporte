GUÍA DEL PROYECTO ENTREGABLES

De la ruta al análisis

La idea, el desarrollo y cómo presentarlo en clase.

20
MICROTALLER INDIVIDUAL · MAURICIO VARELA

Gestión de transporte

Registrar recorridos, vehículos y costos de transporte para entender cómo se mueve una operación y cuánto cuesta.

01 / PROBLEMA

¿Qué situación busca solucionar?

Cuando los recorridos, los kilómetros y los gastos de una flota se anotan de forma dispersa, es difícil saber cuánto se viajó, qué vehículos se usaron y dónde se concentra el gasto. Este proyecto organiza esos datos en una bitácora y los convierte en indicadores que ayudan a controlar y comparar la operación de transporte.

02 / DESARROLLO TÉCNICO

¿Cómo funciona?

El formulario valida y registra fecha, vehículo, conductor, trayecto, tipo de recorrido, kilómetros y costo. JavaScript actualiza la tabla y los gráficos en el navegador; los datos se conservan en el almacenamiento local de este dispositivo. No requiere servidor para la demostración estática.

HTMLCSSJavaScriptlocalStorage
03 / CONSTRUCCIÓN DE DATOS

Base de demostración

Se incluyen más de 20 recorridos ficticios de ejemplo para probar el sistema. Puedes agregar, editar, eliminar y exportar registros. Los datos son didácticos: no describen operaciones reales ni personas reales.

04 / ALCANCE DE LA PUBLICACIÓN

Listo para GitHub Pages

Esta aplicación es estática y se puede publicar como un sitio de GitHub Pages. No necesita Python en el servidor ni instalar programas. Cada visitante empieza con los registros de ejemplo; los cambios que haga se guardan solo en su navegador y no se sincronizan con otros usuarios.

PUBLICACIÓN PÚBLICA

Cómo subirla a GitHub Pages

  1. Crea un repositorio en GitHub y sube los archivos de la aplicación a la raíz del repositorio.
  2. Abre Settings → Pages en ese repositorio.
  3. En “Build and deployment”, elige Deploy from a branch, selecciona la rama main y la carpeta /(root); luego pulsa Save.
  4. Espera a que GitHub publique el sitio y abre el enlace que aparece en esa misma sección para compartirlo con el profesor.

La versión de GitHub Pages conserva su propia copia local en cada navegador. La información no se transmite entre estudiantes ni se centraliza.
